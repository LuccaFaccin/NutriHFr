# NutriHFr

Projet Data Science en nutrition humaine.

## Objectif

Analyser les consommations alimentaires et les apports
nutritionnels de la population francaise a partir des
donnees INCA 3 et Ciqual.

## Technologies

- Python et programmation orientee objet
- pandas et NumPy
- SQLite et SQL
- JupyterLab
- matplotlib et seaborn
- Streamlit
- Git et GitHub

## Organisation

- data/ : donnees brutes et traitees
- docs/ : documentation
- src/ : code Python
- sql/ : base de donnees et requetes SQL
- notebooks/ : analyses exploratoires
- tests/ : tests automatises
- reports/ : resultats et rapports

- INCA 3 - Anses
